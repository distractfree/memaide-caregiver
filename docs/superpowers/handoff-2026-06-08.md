## Architecture recap (see spec for full detail)
- Hybrid stack: `gpt-4o-mini-realtime` for voice (M2) + `gpt-4o-mini` for the brain and
  (M2) vision frame description. `gpt-4o-mini-realtime` has **no vision**, so frames are
  described to text and injected as context.
- M1 is text-in / text-out and async; M2 adds the live media + WebSocket layer.
- Spec: `docs/superpowers/specs/2026-06-06-memaide-agent-foundation-design.md`
- Plan: `docs/superpowers/plans/2026-06-06-memaide-agent-foundation-m1.md`
